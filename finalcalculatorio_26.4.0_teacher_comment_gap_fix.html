What's New

26.4.0 (Latest) — August 2026

  • FinalGrade.io is now owned and maintained by MiniDiamond; TheGeneric and ToxicStudios are retained only as legacy project history.
  • Student View rebuilt into a clean Infinite Campus-inspired progress/gradebook layout using Arial-style typography and compact academic rows.
  • Multiplier 0 assignments are excluded from all grade calculations and labeled “(not included in the grade calculation)”.
  • Reworked top taskbar plus a persistent bottom navigation dock.
  • Custom pixel fire mark with a sharp black outline replaces the emoji brand mark and favicon.
  • Clearview-first title typography with improved system-font fallbacks.
  • New Student Portal term controls in Settings.
  • Updated Privacy Policy and Terms of Service for MiniDiamond ownership and local-only grade storage.
  • Single-file distribution bundles CSS and application JavaScript into this HTML.
  • Runtime JavaScript is source-obfuscated. This is not a substitute for server-side security or true secret storage.
  • Assignments can now store optional due dates in Teacher View and display them in the Student View rows.
  • Student View now completely hides categories that contain no assignments.
  • Poppins now replaces the previous narrow title font across the main interface.
  • Teacher comments now preview in italic text below each Student View assignment title and multiplier.
  • Student assignment grades now include A/B/C/D/F letter grades; blank grades display NG / Not Graded.
  • New 50ms live auto-update engine continuously checks the gradebook and refreshes calculations, Student View grades, letters, comments, statuses, due dates, and local saves when changes are detected.
  • Student View grade cells now show numeric point values only; A–F/NG badges and “Not Graded” text are hidden.
  • Student View now preserves literal/string grades: entering A with a total of 100 displays A/100 instead of treating A as an ungraded value.
  • Student View assignments now automatically list from latest due date to oldest due date within each category.
  • When Student View assignments share the same due date, assignment titles are now sorted Z–A.
  • Every Teacher View category now has a Close Progress Session checkbox. It is off by default; checked progress categories show only a bold grade in Student View with the In-progress label removed.
  • Assignment details now use a cleaner curriculum-style grading panel: Average Score is hidden, and non-default multipliers appear directly below Score.
  • Assignment details now show Missing, Late, Turned In, Excused, Dropped, Incomplete, and Cheated flags as compact outlined pills inside the Grading section.

Privacy Policy

Last Updated: August 23, 2026 • Owner: MiniDiamond

1. Local Grade Data

FinalGrade.io stores gradebook data, preferences, student-view expansion states, and term-display settings in your browser using localStorage. The application does not require a MiniDiamond account or a grade-data server to perform its calculations.

2. What Leaves Your Device

The bundled app does not intentionally upload your gradebook records. If your browser loads external font or icon resources, those providers may receive ordinary network metadata such as your IP address and user-agent. Your entered gradebook values are not intentionally sent with those requests.

3. Educational Records

Do not enter protected or regulated student information unless your school, district, or organization permits use of a local browser tool for that information. You are responsible for device security, browser access, exports, screenshots, and backups.

4. Student Portal Styling

The Student View uses an academic portal layout inspired by common student-information systems. FinalGrade.io is an independent MiniDiamond project and is not affiliated with, sponsored by, or endorsed by Infinite Campus.

5. Source Protection

The single-file release may obfuscate client-side JavaScript to discourage casual copying. Browser-delivered code cannot be made truly secret, and the obfuscation must not be relied on to protect passwords, keys, or confidential information.

6. Changes

MiniDiamond may revise this policy as the app changes. The current “Last Updated” date will identify the active version.

Weighted Grade Calculation Explanation

Example (Weights in Percent):

Math: 80, Weight: 30%
Biology: 90, Weight: 50%
History: 72, Weight: 20%

Weighted Grade = (0.30 × 80) + (0.50 × 90) + (0.20 × 72) = 24 + 45 + 14.4 = 83.4

Example (Weights in Points/Hours):

Math: 80, Weight: 3 points
Biology: 90, Weight: 5 points
History: 72, Weight: 2 points

Weighted Grade = (3×80 + 5×90 + 2×72) / (3+5+2) = (240 + 450 + 144) / 10 = 834 / 10 = 83.4
